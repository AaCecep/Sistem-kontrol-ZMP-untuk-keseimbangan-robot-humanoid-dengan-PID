🦿 ZMP-Based PID Control for Humanoid Robot Balance (ROBOTIS OP3)
📌 Overview

Proyek ini merupakan implementasi sistem kontrol Zero Moment Point (ZMP) berbasis Proportional–Integral–Derivative (PID) untuk meningkatkan kestabilan dinamis robot humanoid ROBOTIS OP3.

Sistem ini dirancang untuk menjaga posisi ZMP tetap berada di dalam Support Polygon saat robot berjalan, termasuk ketika melewati permukaan tidak rata seperti tanjakan dan turunan.

Penelitian ini merupakan bagian dari skripsi Program Studi Teknik Komputer, Fakultas Ilmu Komputer, Universitas Brawijaya (2025).
